# 장소 목록 성능 측정과 개선 (#305)

사용자가 시뮬레이터 조작과 성능 개선 검증을 요청했다.

1. 운영 앱에서 목록 화면을 열어 현재 동작을 확인한다. 운영 반복 부하는 만들지 않는다.
2. H2 전용 repository 테스트에 합성 장소 100/1,000개를 만들고 기존 조회의 SQL 수,
   엔티티 로딩 수, 조회·필터/응답 변환 시간, 스레드 메모리 할당량을 측정한다.
3. 불필요한 엔티티 로딩 비용이 확인되면 목록 전용 scalar DTO 조회를 비교한다.
   최신 작업 선택은 기존 URL 정규화와 작업 ID 기준을 유지하고 응답의 모든 필드·순서를 대조한다.
4. 동일 프로세스에서 워밍업 후 기존/후보 순서를 번갈아 반복 측정한다. 성능 수치로 테스트 성공 여부를
   판단하지 않고 정확성·쿼리 수·불필요한 엔티티 로딩 제거를 회귀 검증한다.
5. 전체 빌드를 확인하고 측정 원본·환경·한계를 기록한다. H2 결과를 운영 지연 개선율로 표현하지 않는다.

운영 배포나 기존 모바일 로그인/데이터 변경은 이번 로컬 비교에 필요하지 않다.
