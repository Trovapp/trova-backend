# PWA 웹 푸시 알림 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 홈 화면에 설치한 PWA에, 자동 일정 초안이 준비됐을 때와 여행 날 비 소식이 새로 생겼을 때 표준 웹 푸시(VAPID)로 알림을 보내고, 누르면 그 화면을 연다.

**Architecture:** 서버는 구독을 `push_subscriptions`에 두고, 초안 READY·비 알림 저장 지점에서 이벤트를 발행한다. 비동기 리스너가 문구(`PushMessages`)를 만들어 `PushNotificationService`에 넘기고, 서비스는 `WebPushTransport`(zerodep + Java `HttpClient`)로 보낸 뒤 응답 코드로 구독을 정리한다. 앱(PWA)은 웹 전용 파일에서 권한·구독을 다루고, 서비스 워커가 알림 표시와 눌렀을 때 이동(`/?open=...`)을 맡는다.

**Tech Stack:** Spring Boot 4(Java 21, JPA, H2 테스트), `com.zerodeplibs:zerodep-web-push-java:2.1.5`, Expo/React Native Web, 서비스 워커, `node --test`(Node 26, .ts 직접 import)

**Spec:** `docs/superpowers/specs/2026-10-14-web-push-design.md` (결정: `docs/adr/0016-pwa-web-push.md`)

## Global Constraints

- 비용 0원, 새 외부 가입 없음. 라이브러리는 `com.zerodeplibs:zerodep-web-push-java:2.1.5`만 추가한다.
- 코드 스타일(docs/adr/0009): 들여쓰기 4칸, 생성자 주입, Lombok 없음, 요청·응답은 `record`, 와일드카드 import·`var` 금지, 테스트 이름은 한글 문장.
- 외부 연동(푸시 발송)은 별도 서비스, `@Async`로.
- 키 설정: `VAPID_PUBLIC_KEY`(비압축 공개 키 base64url, 87자), `VAPID_PRIVATE_KEY`(PKCS8 DER base64 한 줄), `VAPID_SUBJECT`(기본 `mailto:trovapp26@gmail.com`). 키가 비면 알림만 꺼지고 앱은 정상.
- 키 값은 레포·채팅·외부로 보내지 않는다. 운영 키와 로컬 키는 따로 만든다.
- 알림 문구(그대로):
  - 초안: 제목 `일정 초안이 준비됐어요`, 내용 `영상 속 장소 {n}곳으로 {기간} 일정을 짰어요. 확인하고 여행에 담아 보세요.` ({기간}: 1일 `당일`, n일 `{n-1}박 {n}일`)
  - 비: 제목 `{여행 이름}에 비 소식이 있어요`, 내용 `{M월 d일(E)} 강수확률 {p}%예요. {장소} 대신 갈 실내 장소를 볼까요?`
- 이동 값(`open`): `draft:{draftId}`, `trip:{tripId}:place:{tripPlaceId}`. tag: `draft-{draftId}`, `rain-{itineraryId}`.
- 응답 처리: 2xx 성공(`last_success_at`), 404·410 구독 삭제, 429·5xx 2초 뒤 한 번 재시도 후 실패면 WARN, 그 외 4xx WARN. TTL 24시간, urgency normal.
- 로그에 endpoint·키를 남기지 않는다.
- 날씨 확인: `cron = "0 0 8,12,16,20 * * *"`, `zone = "Asia/Seoul"`.
- 앱: 네이티브 동작은 바꾸지 않는다(웹 전용 `.web.ts(x)` + 아무것도 안 하는 기본 파일). [나중에]는 7일 숨김. 권한 요청은 버튼을 눌렀을 때만.

1. 같은 기기에서 A가 로그아웃하지 않고 B가 로그인 → 같은 endpoint 등록: 구독이 B로 옮겨져 A의 알림이 B 기기로 가지 않아야 한다(Task B2 테스트).
2. 사용자 구독이 여러 개인데 그중 하나가 410: 그 하나만 지우고 나머지는 계속 보내야 한다(Task B3 테스트).

5. 트랜잭션 안에서 저장 후 롤백(초안 READY 저장 실패): 알림이 나가지 않아야 한다(Task B5 테스트 — `fallbackExecution`과 AFTER_COMMIT).

package com.trova.backend.push;

import org.junit.jupiter.api.Test;

import java.security.KeyPair;
import java.security.KeyPairGenerator;
import java.security.interfaces.ECPublicKey;
import java.security.spec.ECGenParameterSpec;
import java.util.Base64;

import static org.assertj.core.api.Assertions.assertThat;

class VapidKeysTest {

    /** 테스트용 키 쌍 — [0]=공개 키(base64url 비압축), [1]=비공개 키(PKCS8 base64). */
    static String[] newKeys() throws Exception {
        KeyPairGenerator generator = KeyPairGenerator.getInstance("EC");
        generator.initialize(new ECGenParameterSpec("secp256r1"));
        KeyPair pair = generator.generateKeyPair();
        return new String[] {
                Base64.getUrlEncoder().withoutPadding().encodeToString(uncompressed((ECPublicKey) pair.getPublic())),
                Base64.getEncoder().encodeToString(pair.getPrivate().getEncoded())
        };
    }

    static byte[] uncompressed(ECPublicKey key) {
        byte[] out = new byte[65];
        out[0] = 4;
        copy32(key.getW().getAffineX().toByteArray(), out, 1);
        copy32(key.getW().getAffineY().toByteArray(), out, 33);
        return out;
    }

    private static void copy32(byte[] src, byte[] dst, int offset) {
        int len = Math.min(32, src.length);
        System.arraycopy(src, src.length - len, dst, offset + 32 - len, len);
    }

    @Test
    void 키가_비어_있으면_꺼진다() {
        VapidKeys keys = new VapidKeys("", "", "mailto:a@b.c");
        assertThat(keys.isEnabled()).isFalse();
    }

    @Test
    void 올바른_키면_켜지고_공개_키를_그대로_돌려준다() throws Exception {
        String[] k = newKeys();
        VapidKeys keys = new VapidKeys(k[0], k[1], "mailto:a@b.c");
        assertThat(keys.isEnabled()).isTrue();
        assertThat(keys.publicKey()).isEqualTo(k[0]);
        assertThat(keys.keyPair()).isNotNull();
    }

    @Test
    void 키_형식이_잘못돼도_서버는_뜨고_알림만_꺼진다() {
        VapidKeys keys = new VapidKeys("not-a-key", "also-wrong", "mailto:a@b.c");
        assertThat(keys.isEnabled()).isFalse();
    }
}

package com.trova.backend.push;

import com.zerodeplibs.webpush.VAPIDKeyPair;
import com.zerodeplibs.webpush.VAPIDKeyPairs;
import com.zerodeplibs.webpush.key.PrivateKeySources;
import com.zerodeplibs.webpush.key.PublicKeySources;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

import java.util.Base64;

/**
 * 웹 푸시 VAPID 키(ADR 0016). 키가 비었거나 형식이 틀리면 알림만 끄고 서버는 그대로 뜬다 —
 * 로컬·테스트는 키 없이 돌고, 운영 .env 복사 실수로 서버가 못 뜨는 일을 막는다.
 */
@Component
public class VapidKeys {

    private static final Logger log = LoggerFactory.getLogger(VapidKeys.class);

    private final String publicKey;
    private final String subject;
    private final VAPIDKeyPair keyPair;

    public VapidKeys(@Value("${app.push.vapid-public-key:}") String publicKey,
                     @Value("${app.push.vapid-private-key:}") String privateKey,
                     @Value("${app.push.vapid-subject:mailto:trovapp26@gmail.com}") String subject) {
        this.publicKey = publicKey == null ? "" : publicKey.trim();
        this.subject = subject;
        this.keyPair = load(this.publicKey, privateKey == null ? "" : privateKey.trim());
    }

    private static VAPIDKeyPair load(String publicKey, String privateKey) {
        if (publicKey.isEmpty() || privateKey.isEmpty()) {
            log.info("웹 푸시 꺼짐: VAPID 키가 설정되지 않았어요");
            return null;
        }
        try {
            return VAPIDKeyPairs.of(
                    PrivateKeySources.ofPKCS8Bytes(Base64.getDecoder().decode(privateKey)),
                    PublicKeySources.ofUncompressedBytes(Base64.getUrlDecoder().decode(publicKey)));
        } catch (RuntimeException e) {
            log.warn("웹 푸시 꺼짐: VAPID 키 형식이 올바르지 않아요({})", e.getClass().getSimpleName());
            return null;
        }
    }

    public boolean isEnabled() {
        return keyPair != null;
    }

    public String publicKey() {
        return publicKey;
    }

    public String subject() {
        return subject;
    }

    public VAPIDKeyPair keyPair() {
        return keyPair;
    }
}

package com.trova.backend.entity;

import jakarta.persistence.Column;
import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;
import jakarta.persistence.Index;
import jakarta.persistence.Table;

import java.time.LocalDateTime;

/**
 * PWA 웹 푸시 구독(ADR 0016). 기기(브라우저)마다 하나라 한 사용자가 여러 개를 가질 수 있다.
 * share_keys처럼 user_id만 들고 FK는 두지 않는다 — 탈퇴 때 UserAccountService가 함께 지운다.
 */
@Entity
@Table(name = "push_subscriptions", indexes = {
        @Index(name = "idx_push_subscriptions_user", columnList = "user_id")
})
public class PushSubscription {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "user_id", nullable = false)
    private Long userId;

    @Column(nullable = false, unique = true, length = 1000)
    private String endpoint;

    @Column(nullable = false, length = 200)
    private String p256dh;

    @Column(nullable = false, length = 100)
    private String auth;

    @Column(name = "created_at", nullable = false)
    private LocalDateTime createdAt;

    @Column(name = "last_seen_at", nullable = false)
    private LocalDateTime lastSeenAt;

    @Column(name = "last_success_at")
    private LocalDateTime lastSuccessAt;

    protected PushSubscription() {
    }

    public PushSubscription(Long userId, String endpoint, String p256dh, String auth) {
        this.userId = userId;
        this.endpoint = endpoint;
        this.p256dh = p256dh;
        this.auth = auth;
        this.createdAt = LocalDateTime.now();
        this.lastSeenAt = this.createdAt;
    }

    /** 같은 기기에서 다시 등록 — 다른 사람이 로그인했을 수도 있어 사용자까지 덮어쓴다. */
    public void reassign(Long userId, String p256dh, String auth) {
        this.userId = userId;
        this.p256dh = p256dh;
        this.auth = auth;
        this.lastSeenAt = LocalDateTime.now();
    }

    public void markSuccess() {
        this.lastSuccessAt = LocalDateTime.now();
    }

    public Long getId() { return id; }
    public Long getUserId() { return userId; }
    public String getEndpoint() { return endpoint; }
    public String getP256dh() { return p256dh; }
    public String getAuth() { return auth; }
    public LocalDateTime getCreatedAt() { return createdAt; }
    public LocalDateTime getLastSeenAt() { return lastSeenAt; }
    public LocalDateTime getLastSuccessAt() { return lastSuccessAt; }
}

package com.trova.backend.controller;

import com.trova.backend.entity.PushSubscription;
import com.trova.backend.entity.User;
import com.trova.backend.push.VapidKeys;
import com.trova.backend.repository.PushSubscriptionRepository;
import com.trova.backend.service.CurrentUserService;
import org.springframework.http.ResponseEntity;
import org.springframework.security.core.Authentication;
import org.springframework.transaction.annotation.Transactional;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestBody;
import org.springframework.web.bind.annotation.RestController;

/** PWA 웹 푸시 구독(#185, ADR 0016). 앱은 열 때마다 구독을 다시 보내 끊긴 구독을 되살린다. */
@RestController
public class PushController {

    private static final int MAX_ENDPOINT = 1000;

    public record PublicKeyResponse(String publicKey) { }

    public record Keys(String p256dh, String auth) { }

    public record SubscribeRequest(String endpoint, Keys keys) { }

    public record UnsubscribeRequest(String endpoint) { }

    private final VapidKeys vapidKeys;
    private final PushSubscriptionRepository subscriptions;
    private final CurrentUserService currentUserService;

    public PushController(VapidKeys vapidKeys, PushSubscriptionRepository subscriptions,
                          CurrentUserService currentUserService) {
        this.vapidKeys = vapidKeys;
        this.subscriptions = subscriptions;
        this.currentUserService = currentUserService;
    }

    @GetMapping("/api/push/public-key")
    public ResponseEntity<PublicKeyResponse> publicKey(Authentication authentication) {
        currentUserService.resolve(authentication);
        if (!vapidKeys.isEnabled()) {
            return ResponseEntity.notFound().build();
        }
        return ResponseEntity.ok(new PublicKeyResponse(vapidKeys.publicKey()));
    }

    @PostMapping("/api/push/subscriptions")
    @Transactional
    public ResponseEntity<Void> subscribe(Authentication authentication, @RequestBody SubscribeRequest request) {
        User user = currentUserService.resolve(authentication);
        if (!isValid(request)) {
            return ResponseEntity.badRequest().build();
        }
        subscriptions.findByEndpoint(request.endpoint()).ifPresentOrElse(
                existing -> existing.reassign(user.getId(), request.keys().p256dh(), request.keys().auth()),
                () -> subscriptions.save(new PushSubscription(
                        user.getId(), request.endpoint(), request.keys().p256dh(), request.keys().auth())));
        return ResponseEntity.noContent().build();
    }

    @DeleteMapping("/api/push/subscriptions")
    public ResponseEntity<Void> unsubscribe(Authentication authentication, @RequestBody UnsubscribeRequest request) {
        User user = currentUserService.resolve(authentication);
        if (request != null && request.endpoint() != null) {
            subscriptions.deleteByEndpointAndUserId(request.endpoint(), user.getId());
        }
        return ResponseEntity.noContent().build();
    }

    private static boolean isValid(SubscribeRequest request) {
        return request != null && request.endpoint() != null
                && request.endpoint().startsWith("https://") && request.endpoint().length() <= MAX_ENDPOINT
                && request.keys() != null
                && notBlank(request.keys().p256dh(), 200) && notBlank(request.keys().auth(), 100);
    }

    private static boolean notBlank(String value, int max) {
        return value != null && !value.isBlank() && value.length() <= max;
    }
}

package com.trova.backend.push;

import com.trova.backend.entity.PushSubscription;
import com.zerodeplibs.webpush.httpclient.StandardHttpClientRequestPreparer;
import org.springframework.stereotype.Component;

import java.net.http.HttpClient;
import java.net.http.HttpRequest;
import java.net.http.HttpResponse;
import java.time.Duration;
import java.util.concurrent.TimeUnit;

/** 표준 웹 푸시(RFC 8030/8291/8292) 실제 발송 — zerodep 라이브러리로 암호화·VAPID 서명, 전송은 Java 기본 HttpClient. */
@Component
public class ZerodepWebPushTransport implements WebPushTransport {

    private final VapidKeys keys;
    private final HttpClient httpClient = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(5)).build();

    public ZerodepWebPushTransport(VapidKeys keys) {
        this.keys = keys;
    }

    @Override
    public int send(PushSubscription subscription, byte[] payload, String topic) throws Exception {
        com.zerodeplibs.webpush.PushSubscription target = new com.zerodeplibs.webpush.PushSubscription();
        target.setEndpoint(subscription.getEndpoint());
        com.zerodeplibs.webpush.PushSubscription.Keys targetKeys = new com.zerodeplibs.webpush.PushSubscription.Keys();
        targetKeys.setP256dh(subscription.getP256dh());
        targetKeys.setAuth(subscription.getAuth());
        target.setKeys(targetKeys);

        HttpRequest request = StandardHttpClientRequestPreparer.getBuilder()
                .pushSubscription(target)
                .vapidJWTExpiresAfter(15, TimeUnit.MINUTES)
                .vapidJWTSubject(keys.subject())
                .pushMessage(payload)
                .ttl(24, TimeUnit.HOURS)
                .urgencyNormal()
                .topic(topic)
                .build(keys.keyPair())
                .toRequestBuilder()
                .timeout(Duration.ofSeconds(10))
                .build();
        return httpClient.send(request, HttpResponse.BodyHandlers.discarding()).statusCode();
    }
}

package com.trova.backend.push;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.trova.backend.entity.PushSubscription;
import com.trova.backend.repository.PushSubscriptionRepository;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.time.Duration;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;

/**
 * 사용자의 모든 기기에 웹 푸시를 보낸다(ADR 0016). 404·410은 사라진 구독이라 지우고,
 * 429·5xx는 무료 푸시 서버의 요청 제한을 지키려 2초 뒤 한 번만 다시 보낸다. 로그에 endpoint·키는 남기지 않는다.
 */
@Service
public class PushNotificationService {

    private static final Logger log = LoggerFactory.getLogger(PushNotificationService.class);

    public record Result(int sent, int removed, int failed) { }

    private final VapidKeys keys;
    private final PushSubscriptionRepository repository;
    private final WebPushTransport transport;
    private final ObjectMapper objectMapper;
    private final Duration retryDelay;

    @Autowired
    public PushNotificationService(VapidKeys keys, PushSubscriptionRepository repository,
                                   WebPushTransport transport, ObjectMapper objectMapper) {
        this(keys, repository, transport, objectMapper, Duration.ofSeconds(2));
    }

    PushNotificationService(VapidKeys keys, PushSubscriptionRepository repository, WebPushTransport transport,
                            ObjectMapper objectMapper, Duration retryDelay) {
        this.keys = keys;
        this.repository = repository;
        this.transport = transport;
        this.objectMapper = objectMapper;
        this.retryDelay = retryDelay;
    }

    public Result sendToUser(Long userId, String kind, PushMessage message) {
        if (!keys.isEnabled()) {
            return new Result(0, 0, 0);
        }
        List<PushSubscription> targets = repository.findByUserId(userId);
        if (targets.isEmpty()) {
            return new Result(0, 0, 0);
        }
        byte[] payload = payload(message);
        int sent = 0;
        int removed = 0;
        int failed = 0;
        for (PushSubscription subscription : targets) {
            int status = sendWithRetry(subscription, payload, message.tag());
            if (status >= 200 && status < 300) {
                subscription.markSuccess();
                repository.save(subscription);
                sent++;
            } else if (status == 404 || status == 410) {
                repository.delete(subscription);
                removed++;
            } else {
                failed++;
            }
        }
        log.info("웹 푸시 {} user={} 구독 {}개 → 성공 {}·삭제 {}·실패 {}",
                kind, userId, targets.size(), sent, removed, failed);
        return new Result(sent, removed, failed);
    }

    private int sendWithRetry(PushSubscription subscription, byte[] payload, String topic) {
        int status = sendOnce(subscription, payload, topic);
        if (status == 429 || status >= 500 || status < 0) {
            sleep();
            status = sendOnce(subscription, payload, topic);
        }
        if (!(status >= 200 && status < 300) && status != 404 && status != 410) {
            log.warn("웹 푸시 실패: subscriptionId={} 상태 {}", subscription.getId(), status);
        }
        return status;
    }

    /** 연결 실패 등 예외는 -1(서버 오류처럼 한 번 다시 보낸다). */
    private int sendOnce(PushSubscription subscription, byte[] payload, String topic) {
        try {
            return transport.send(subscription, payload, topic);
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
            return -1;
        } catch (Exception e) {
            log.warn("웹 푸시 전송 오류: subscriptionId={} {}", subscription.getId(), e.getClass().getSimpleName());
            return -1;
        }
    }

    private void sleep() {
        if (retryDelay.isZero()) {
            return;
        }
        try {
            Thread.sleep(retryDelay.toMillis());
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
        }
    }

    private byte[] payload(PushMessage message) {

        body.put("title", message.title());
        body.put("body", message.body());
        body.put("open", message.open());
        body.put("tag", message.tag());

            return objectMapper.writeValueAsBytes(body);

            throw new IllegalStateException("웹 푸시 내용 만들기 실패", e);
        }
    }
}

// 웹 푸시(백엔드 #185, ADR 0016)에서 화면·브라우저와 무관한 판단만 모은다. node --test로 검사한다(scripts/push-logic.test.mjs).

export type OpenTarget = { kind: "draft"; draftId: number } | { kind: "trip"; tripId: number; tripPlaceId?: number };

const POSITIVE_INT = /^[1-9]\d{0,17}$/;

/** 서버가 알림에 실어 보낸 이동 값(draft:12, trip:45:place:678). 형식이 다르면 null — 주소에서 온 값이라 엄격하게. */
export function parseOpenTarget(open: string | null | undefined): OpenTarget | null {
  if (!open) return null;
  const parts = open.split(":");
  if (parts[0] === "draft" && parts.length === 2 && POSITIVE_INT.test(parts[1])) {
    return { kind: "draft", draftId: Number(parts[1]) };
  }
  if (parts[0] === "trip" && POSITIVE_INT.test(parts[1] ?? "")) {
    if (parts.length === 2) return { kind: "trip", tripId: Number(parts[1]) };
    if (parts.length === 4 && parts[2] === "place" && POSITIVE_INT.test(parts[3])) {
      return { kind: "trip", tripId: Number(parts[1]), tripPlaceId: Number(parts[3]) };
    }
  }
  return null;
}

export const SNOOZE_MS = 7 * 24 * 60 * 60 * 1000;

export type PromptInput = {
  standalone: boolean;
  supported: boolean;
  permission: "default" | "granted" | "denied";
  hasPublicKey: boolean;
  loggedIn: boolean;
  subscribed: boolean;
  snoozedUntil: number | null;
  now: number;
};

/** 권한 묻는 카드: 설치한 앱 + 지원 + 로그인 + 서버 키 있음 + (아직 안 물음 또는 허용했는데 구독 없음) + [나중에] 7일 지남. */
export function shouldShowPushPrompt(input: PromptInput): boolean {
  if (!input.standalone || !input.supported || !input.loggedIn || !input.hasPublicKey) return false;
  if (input.permission === "denied") return false;
  if (input.permission === "granted" && input.subscribed) return false;
  if (input.snoozedUntil !== null && input.snoozedUntil > input.now) return false;
  return true;
}

/** pushManager.subscribe의 applicationServerKey용. */
export function base64UrlToBytes(value: string): Uint8Array {
  const padded = value.replace(/-/g, "+").replace(/_/g, "/") + "=".repeat((4 - (value.length % 4)) % 4);
  const binary = atob(padded);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes;
}

import { deletePushSubscription, getPushPublicKey, savePushSubscription } from "@/lib/api/push";
import { getToken } from "@/lib/tokenStorage";
import { SNOOZE_MS, base64UrlToBytes, shouldShowPushPrompt } from "@/lib/pushLogic";

// PWA 웹 푸시(백엔드 #185, ADR 0016). 아이폰은 홈 화면에 설치한 앱(iOS 16.4+)에서만 되고, 권한은 사용자가 버튼을 눌렀을 때만 묻는다.
export type PushStatus = "unsupported" | "blocked" | "off" | "on";

const SNOOZE_KEY = "trova.pushPromptSnoozedUntil";

function isStandalone(): boolean {
  return (
    window.matchMedia?.("(display-mode: standalone)").matches === true ||
    (navigator as Navigator & { standalone?: boolean }).standalone === true
  );
}

function isSupported(): boolean {
  return "serviceWorker" in navigator && "PushManager" in window && "Notification" in window;
}

async function currentSubscription(): Promise<PushSubscription | null> {
  const registration = await navigator.serviceWorker.ready;
  return registration.pushManager.getSubscription();
}

function toBody(subscription: PushSubscription) {
  const json = subscription.toJSON();
  return { endpoint: json.endpoint ?? "", keys: { p256dh: json.keys?.p256dh ?? "", auth: json.keys?.auth ?? "" } };
}

export async function getPushStatus(): Promise<PushStatus> {
  if (!isSupported() || !isStandalone()) return "unsupported";
  if (Notification.permission === "denied") return "blocked";
  if (Notification.permission !== "granted") return "off";
  return (await currentSubscription()) ? "on" : "off";
}

export async function enablePush(): Promise<PushStatus> {
  if (!isSupported()) return "unsupported";
  const permission = await Notification.requestPermission();
  if (permission === "denied") return "blocked";
  if (permission !== "granted") return "off";
  const publicKey = await getPushPublicKey();
  if (!publicKey) return "off";
  const registration = await navigator.serviceWorker.ready;
  const subscription =
    (await registration.pushManager.getSubscription()) ??
    (await registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: base64UrlToBytes(publicKey) }));
  await savePushSubscription(toBody(subscription));
  return "on";
}

export async function disablePush(): Promise<void> {
  if (!isSupported()) return;
  const subscription = await currentSubscription().catch(() => null);
  if (!subscription) return;
  await deletePushSubscription(subscription.endpoint).catch(() => {});
  await subscription.unsubscribe().catch(() => false);
}

/** 앱을 열 때마다 — 구독이 바뀌거나 서버에서 지워졌어도 되살린다. 권한이 없으면 아무것도 묻지 않는다. */
export async function refreshPushSubscription(): Promise<void> {
  if (!isSupported() || !isStandalone() || Notification.permission !== "granted") return;
  const publicKey = await getPushPublicKey();
  if (!publicKey) return;
  const registration = await navigator.serviceWorker.ready;
  const subscription =
    (await registration.pushManager.getSubscription()) ??
    (await registration.pushManager.subscribe({ userVisibleOnly: true, applicationServerKey: base64UrlToBytes(publicKey) }));
  await savePushSubscription(toBody(subscription));
}

function readSnooze(): number | null {
  try {
    const raw = localStorage.getItem(SNOOZE_KEY);
    return raw ? Number(raw) : null;
  } catch {
    return null;
  }
}

export function snoozePushPrompt(): void {
  try {
    localStorage.setItem(SNOOZE_KEY, String(Date.now() + SNOOZE_MS));
  } catch {
    // 저장소가 막힌 브라우저(사생활 보호 모드)면 이번 화면에서만 숨긴다.
  }
}

export async function isPushPromptVisible(): Promise<boolean> {
  const supported = isSupported();
  const standalone = isStandalone();
  if (!supported || !standalone) return false;
  const loggedIn = Boolean(await getToken());
  const permission = Notification.permission as "default" | "granted" | "denied";
  const hasPublicKey = loggedIn ? Boolean(await getPushPublicKey().catch(() => null)) : false;
  const subscribed = permission === "granted" ? Boolean(await currentSubscription().catch(() => null)) : false;
  return shouldShowPushPrompt({
    standalone, supported, permission, hasPublicKey, loggedIn, subscribed, snoozedUntil: readSnooze(), now: Date.now(),
  });
}

function go(target: OpenTarget) {
  const screen =
    target.kind === "draft"
      ? { name: "PlanTrip" as const, params: { draftId: target.draftId } }
      : { name: "TripDetail" as const, params: { id: target.tripId, weatherAlertTripPlaceId: target.tripPlaceId } };
  navigationRef.reset({ index: 1, routes: [{ name: "MainTabs", params: { screen: "Home" } }, screen] });
}

export function PushOpenListener() {
  const { user } = useAuth();

  useEffect(() => {
    const params = new URLSearchParams(window.location.search);
    const target = parseOpenTarget(params.get("open"));
    if (params.has("open")) window.history.replaceState(null, "", "/");
    if (target) setPendingOpen(target);

    function onMessage(event: MessageEvent) {
      if (event.data?.type !== "trova-open") return;
      const t = parseOpenTarget(event.data.open);
      if (!t) return;
      if (navigationRef.isReady() && user) go(t);
      else setPendingOpen(t);
    }
    navigator.serviceWorker?.addEventListener("message", onMessage);
    return () => navigator.serviceWorker?.removeEventListener("message", onMessage);
  }, [user]);

  useEffect(() => {
    if (!user) return;
    // 내비게이션이 아직이면 잠깐 뒤 다시 본다(로그인 직후 화면 전환 중).
    const timer = setInterval(() => {
      if (!navigationRef.isReady()) return;
      clearInterval(timer);
      const target = takePendingOpen();
      if (target) go(target);
    }, 100);
    return () => clearInterval(timer);
  }, [user]);

  return null;
}
