# 파이프라인 진행 로그 UTF-8 경계 보존 (#278)

- poll마다 String으로 디코딩하던 조각을 원본 바이트로 보관한다. LF로 끝난 줄을 완성한 뒤 UTF-8 디코딩/JSON 해석한다.
- 한국어 3바이트/이모지 4바이트의 모든 분할 위치에서 문자가 보존돼야 한다. 여러 줄과 일반 stderr·잘못된 JSON 사이의 정상 진행도 유지한다.
- 기존 newline이 없는 마지막 줄은 계속 대기하며 CRLF/빈 줄/일반 로그 처리, callback의 실패 전달은 기존 동작을 유지한다.
- 직접 파일 append/poll로 모든 경계와 한 바이트씩 쓰기를 확인하고, 기존 실제 Python Runner/cleanup 테스트를 포함한 전체 build로 확인한다. 외부 API/운영 실행 없음.
- 빈 진행 JSON도 잘못된 줄로 건너뛰며 다음 정상 줄을 계속 읽는다.
