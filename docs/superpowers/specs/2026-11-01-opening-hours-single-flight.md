# 영업시간 진행 요청 공유 (#132)

사용자가 Google 저장 정책 확인 후 권장한 동시 요청 공유를 선택했다. 새 90일/사용자간 영구 공유 캐시는 추가하지 않는다. 기존SavedPlace 저장정책까지허용됨을주장하지않으며해당정책은별도검토대상이다.

- 외부쿼리가동일한name/latitude/longitude의진행중조회만단일JVM에서공유한다. 가까운좌표/이름별칭을추측해합치지않는다.
- owner만Google호출/API로그와실제호출수1을기록한다. 대기자는0이며각자응답nearest판정과자신의SavedPlace저장을한다.
- 정상/실패/Error에서future완료및소유map항목제거, 완료후새독립요청은기존정책대로호출한다. 응답을future캐시에장기보관하지않는다.
- 대기자인터럽트는자기대기만종료·플래그보존,owner취소하지않는다. Google실패는hoursCheckedAt을남기지않아후속독립재시도가능.
- 실제Google/DB호출없이 fakeclient/latch/thread로동시성과저장경계를검증한다. 새외부서비스/스키마/운영변경없음.
