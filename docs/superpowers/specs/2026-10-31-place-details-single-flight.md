# 장소 상세 동시 생성 공유 (#276)

- placeId별 진행 Future를 putIfAbsent로 등록하고 소유 요청 하나가 기존 캐시/상세/요약/전화 흐름을 실행한다. 동시 대기자는 같은 반환값 또는 예외를 받는다.
- 실패 fallback도 진행 중 요청끼리 공유한다. 완료/실패 후 소유 Future만 제거해 다음 요청의 기존 캐시/재시도를 허용한다. 없는 장소와 DB 실패도 항목을 남기지 않는다.
- 대기자 인터럽트는 해당 대기만 종료하고 플래그를 보존한다. 공유 생성은 취소하지 않는다. 서로 다른 placeId는 병렬로 진행한다.
- 캐시 정책, 응답 DTO, 요청별 한도, 외부 API/요약 호출의 기존 재시도는 바꾸지 않는다. 단일 JVM 범위이며 외부 서비스 신규 도입/실제 호출은 없다.
- 성공/상세 실패/요약 실패/저장 실패/전화 생성/독립 재시도/다른 장소 병렬/인터럽트의 결정적 동시성 테스트와 기존 전체 build로 검증한다.
