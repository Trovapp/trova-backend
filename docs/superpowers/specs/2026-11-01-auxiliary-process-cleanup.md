# 보조 Python 실행기 수명주기 (#284)

- 대상: 리뷰 요약·태깅·선택·검증·일정 생성의 기존 5개 실행기. 입력 JSON/경로, 결과 파서, API 기록, 기본 2분 제한과 재시도 정책은 유지한다.
- 기존 PipelineRunner의 검증된 부모/관찰 자식 종료 로직을 공통 클래스로 추출해 동일 경로를 공유한다. 주 파이프라인 5분 제한과 진행 처리 동작은 유지한다.
- 보조 실행기는 stdout/stderr를 소유 작업 폴더의 파일로 받는다. 종료를 먼저 확인하고 출력 수집 후 정리한다. 실패/인터럽트/시간초과도 같은 finally 경로다. 미확인 종료는 파일 보존, 인터럽트 플래그 보존.
- 새 작업 폴더만 생성해 소유한다. 이미 남은 폴더는 덮지 않으며, 생성 실패 시 기존 경로를 삭제하지 않는다.
- 실제 Python 부모/자식으로 5개 어댑터의 인터럽트·짧은 시간초과·정상/오류 종료·입력 payload/큰 UTF8 출력·종료 미확인 파일 보존을 검증한다. 외부 API는 사용하지 않는다.
- 그 뒤 운영 버전/헬스/로그의 ERROR·실패 작업·실행 시간 표본을 읽기 전용으로 확인한다. 새 수정의 GitHub 머지·배포는 별도 선택이며 이번 점검에서는 운영 파일을 바꾸지 않는다.
