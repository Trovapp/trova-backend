# Expo 티켓 성공 판정 보강 (#277)

- 배열의 status=ok만 성공(null)으로 변환한다. 오류는 기존 코드/메시지 처리, 다른 상태/빈/null/비객체 티켓은 InvalidTicket 실패다.
- 모든 배열 항목의 위치를 유지해 뒤의 정상 티켓/DeviceNotRegistered가 잘못된 토큰에 적용되지 않도록 한다.
- 오류 코드는 details.error의 비어 있지 않은 문자열만 사용하고 설명 문구는 코드로 사용하지 않으며, 형식이 잘못돼도 뒤 티켓을 계속 처리한다. data 배열이 없거나 JSON이 깨지면 기존의 빈 티켓 목록(발송 서비스에서 모두 실패) 유지.
- 파서 행렬과 실제 발송 서비스+fake client로 성공 시각/삭제 대상/성공·실패 수를 검증한다. HTTP 전송/재시도/토큰 보관 정책과 의존성은 바꾸지 않는다.
