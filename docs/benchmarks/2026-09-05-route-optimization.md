# 동선 최적화 — 이동거리 감소 실측

- **날짜**: 2026-09-05
- **환경**: 로컬 개발 서버 (`./gradlew bootRun`), 실제 Supabase(Postgres) DB
- **대상**: ProcessingJob 16 (`부산만 가기엔 아까운 김해 당일치기로 노는법`), 1일차 장소 5개 — 전부 카카오 지오코딩으로 실좌표 확보된 케이스
- **도구**: `RouteOptimizer`(haversine 기반 편도 최단경로, n≤10이면 완전탐색) + 수동 haversine 재계산(Python, 검증용)
- **재현 방법**:
  1. `POST /api/places/videos/16/days/1/optimize-route` 호출 (인증 세션 필요)
  2. 응답의 `orderInDay` 순서로 각 지점 좌표를 뽑아 haversine 합산

## 참고

- 직선거리(haversine) 기준이라 실제 도로 이동거리와는 다를 수 있음 — 카카오/구글 Directions API 없이 0원으로 계산한 근사치임을 명시
- 이 케이스는 하루 방문지 5곳(완전탐색 상한 10개 이내)이라 전역 최적해(global optimum)임 — nearest-neighbor 근사가 아님
- DB 반영까지 확인함: `saved_places.order_in_day`가 API 응답과 동일하게 갱신됨(직접 SQL 조회로 검증)
