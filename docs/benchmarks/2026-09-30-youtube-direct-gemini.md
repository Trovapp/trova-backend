# 유튜브 장소 추출: 영상 다운로드 vs Gemini 유튜브 링크 직접 입력 (2026-09-30, #57)

## 배경
운영 서버(Oracle E2.1.Micro, 도쿄, 데이터센터 IP)에서 유튜브 분석이 전부 실패했다. yt-dlp 다운로드를 유튜브가 봇으로 막았다
(`Sign in to confirm you're not a bot`). 로컬(Mac, 가정용 IP)은 성공한다. 가정용 IP이고, 막히면 크롬 쿠키로 다시 시도하기 때문이다.

Gemini API는 공개 유튜브 링크를 입력으로 받는다(미리보기, 무료 티어 하루 8시간 분량, 초당 약 100토큰 —
[공식 문서](https://ai.google.dev/gemini-api/docs/video-understanding), 2026-09-30 확인). 서버가 영상을 내려받지 않으니 IP 차단과 무관하다.

## 측정 방법
- 샘플: `pipeline-test/samples.txt`의 유튜브 쇼츠 25개(부산·제주·서울·강릉·전주 각 5개, 2026-08 수집)
- 기존 방식: `run_pipeline.run`(다운로드 → 자막·오디오·프레임 → 수집·필터 2단계)
- 새 방식: 같은 수집·필터 프롬프트에 영상 대신 `file_data.file_uri`(유튜브 링크)를 넣음. 제목은 유튜브 oEmbed
- 모델: `gemini-3.5-flash-lite`, 영상당 Gemini 2회 호출
- 시간: 영상 하나를 처리하는 전체 시간(스크립트 기준, 서버 API·지오코딩 제외)
