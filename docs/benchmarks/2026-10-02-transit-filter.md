# 거쳐 간 공항·역·항구를 장소에서 빼기 (#91)

## 문제
- 운영 분석에서 "김해국제공항 국제선청사/국내선청사"가 장소로 저장됐다(2026-10-02 테스트 계정 분석에서도 재현).
- 역·정류장을 빼는 규칙(커밋 `1e51460`)은 열린 PR #8에만 있고 main과 운영 서버에는 없었다. main의 필터에는 행정구역명·일반명사 규칙만 있었다.

## 정답 기준 (영상 문맥)
Gemini에 영상 링크를 주고 각 장소가 어떤 문맥으로 나오는지 인용과 함께 물었다.

| 장소 | 영상 속 문구 | 판정 | 바라는 결과 |
|---|---|---|---|
| 김해공항 | "김해공항에 도착해서" | 도착 | 빼기 |
| 묵호역 | "바다 감상하며 묵호에 도착할 거야"(KTX) | 도착 | 빼기 |
| 묵호항 | "묵호항을 내려다볼 수 있는 논골담길" | 논골담길에서 보는 풍경 | 판단이 갈림 |
| 어달항 | "어달항이 1열로 보이는 카페 가서 음료도 한잔" | 방문 | 남기기 |

## 측정 (로컬 Mac, `run_pipeline.py` 전체 실행, 유튜브는 Gemini 링크 직접 입력)
- 스크립트: `docs/benchmarks/scripts/transit_bench.py`, 원본 결과: `docs/benchmarks/results/2026-10-02-transit-filter/`
- 수정 전 표본은 두 번 돌렸다(첫 수정이 적용되지 않아 같은 코드로 한 번 더 측정됨).

| 장소 | 수정 전 | 수정 후 |
|---|---|---|
| 김해공항 | 10/10 | **0/5** |
| 김해의 다른 6곳 | 매번 6곳 모두 | 매번 6곳 모두 |
| 묵호역 | 4/6 | **0/3** |
| 어달항 | 6/6 | 3/3 |
| 묵호항 | 6/6 | **1/3** |
| 묵호 핵심 장소(하평해변, 어달삼거리, 카페어달, 논골담길, 비비소) | 매번 | 매번 |

- 한 번 분석 시간은 전후 모두 약 5~7초로 차이 없다.

## 해석
- 거쳐 간 공항과 역은 빠졌고, 목적지인 어달항은 남았다.
- 묵호항이 줄었다. 영상에서 묵호항은 논골담길에서 내려다보는 풍경으로만 나와 실제 방문지는 논골담길이다. 틀린 제외로 단정하지 않지만, 풍경으로만 나온 항구·역이 빠질 수 있다는 부작용이다.

## 확인하지 않은 것
- 영상 2개, 반복 3~5회 표본이다. 공항이나 항구가 목적지인 다른 영상(공항 맛집, 항구 수산시장 등)은 재보지 않았다.
- 인스타그램 경로(오디오 + 게시물 설명)는 재보지 않았다. 같은 필터 프롬프트를 쓴다.
