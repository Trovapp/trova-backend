# 인스타그램 릴스: 게시물 설명(캡션)을 장소 추출에 활용 (2026-09-30, #59)

## 배경
릴스 게시물 설명에는 작성자가 쓴 장소 태그와 주소가 그대로 있는 경우가 많다(예: `🏷️ 요미우돈교자 / 부산 해운대구 우동1로 45 1층`).
그런데 파이프라인은 설명을 쓰지 않고 영상의 소리·화면만 봤다. 인스타 링크는 이번에 처음 실제 검증했다(그전엔 DB·샘플에 인스타 작업이 없었다).

## 측정 방법
- 샘플: 공개 한국 여행·맛집 릴스 16개(부산 6, 제주 4, 강릉·전주 6), 2026-09-30 웹 검색으로 수집
- 릴스마다 영상은 한 번만 내려받고, 같은 자막·오디오·프레임으로 **설명 없이 / 설명 포함** 두 번 추출(모델 `gemini-3.5-flash-lite`)
- 설명은 영상을 받지 않고 정보 조회(`yt-dlp --skip-download --dump-single-json`)로 가져옴
- 정답: 설명의 🏷 태그가 있는 경우만 자동 채점이 가능해서(실질 2개), 나머지는 설명과 결과를 나란히 놓고 직접 비교

## 함께 발견한 것
- **오디오 트랙이 없는 릴스**(화면만 있는 영상)는 오디오 추출에서 파이프라인 전체가 실패했다(두 환경 공통)
  - 오디오가 없으면 건너뛰도록 수정했다
  - 수정 후 로컬에서 같은 릴스가 성공했다(`솔내음한정식해운대점`)

- 인스타 제목은 "Video by 계정명" 자동 제목이라 설명의 첫 줄을 제목으로 쓴다. 해시태그·기호만 있는 줄은 건너뛴다
