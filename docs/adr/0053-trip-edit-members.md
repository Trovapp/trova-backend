# ADR 0053: 여행 멤버와 공동 편집

- 상태: 채택
- 날짜: 2026-11-21
- 관련: #498, [0046 공유 링크](0046-trip-share-link.md), [0047 여행 복사](0047-trip-copy-from-share-link.md), [0025 재구성 접수](0025-replan-admission-quota.md)

## 배경

사용자는 친구가 같은 여행을 자기 목록에서 열고 일정을 함께 고치기를 원한다. 기존 공개 미리보기와 독립 복사를 유지하고, 로그인한 사람이 원본 여행에 참여하는 선택지를 추가한다.

## 결정

- trips.user_id는 소유자를 가리킨다. 생성 시 trip_members에 OWNER를 저장한다. 스키마 초기화 후 웹 요청 수신 전에 기존 여행의 누락된 OWNER를 채우며 실패하면 기동을 중단한다.
- 유효한 토큰으로 참여하면 여행 행을 잠그고 OWNER를 포함한 상한 10명을 검사한다. 링크 교체도 같은 여행 행을 잠근다. 멤버는 편집할 수 있고 여행 삭제·내보내기·링크 끄기와 재발급은 OWNER가 한다.
- 같은 여행에서 동일한 옵션으로 진행 중인 재구성을 재사용한다. 새 작업을 시작하는 사용자 몫으로만 한도를 계산한다.
- 기존 앱과 호환되도록 If-Match는 선택 사항이다. 여행과 장소는 각각 자기 버전을 사용한다. 성공한 편집 응답은 커밋된 여행 버전을 헤더로 돌려주고, 충돌 시 409와 최신 여행을 반환한다. 활동 기록은 일정 수정과 같은 트랜잭션으로 커밋하고 최근 100건을 유지한다.

## 기존 링크에 대한 사용자 결정과 위험

2026-11-21 사용자는 실사용 중인 공유 링크가 없다는 이유로 기존 보기용 링크도 배포 직후 편집 참여에 사용할 수 있도록 결정했다. 과거 전달·재공유된 링크가 있으면 그 링크를 가진 사람도 로그인 후 참여할 수 있다. 만든 사람은 링크를 새로 만들어 이전 토큰을 무효화하고 이미 참여한 사용자는 멤버 목록에서 내보낼 수 있다. 링크를 교체해도 기존 멤버는 유지된다.

## 검토한 대안

기존 토큰을 보기·복사용으로 유지하고 OWNER가 새 초대 링크를 발급하는 방식은 이미 퍼진 링크의 권한을 제한한다. 이번 결정은 실사용 링크가 없는 시점에 공유 링크 하나로 두 동작을 선택하는 흐름을 유지한다.
