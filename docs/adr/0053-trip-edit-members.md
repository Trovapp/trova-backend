# 0053. 여행 멤버와 공동 편집

2026-11-21 확정. #498. ADR 0046의 공개 미리보기와 0047의 독립 복사를 유지하면서 인증한 사용자의 참여를 추가한다.

기존 trips.user_id가 소유자를 가리킨다. 생성 시 trip_members에 OWNER를 함께 저장하고 시작 시 누락된 기존 소유자 행을 채운다. 공유 토큰이 유효하면 여행 행을 잠그고 멤버 수를 확인한다. 링크 교체도 같은 여행을 잠그므로 동시 참여·해제·교체가 직렬화된다. 비멤버는 403, 존재하지 않는 자원과 무효 토큰은 404를 반환한다.

일정 변경은 여행과 해당 장소 버전을 사용한다. 기존 클라이언트와 호환되도록 If-Match는 선택 사항이다. 클라이언트가 오래된 값을 차례로 제출하는 경우까지 감지하려면 버전을 보내야 한다. 변경 기록과 일정 수정을 같은 트랜잭션으로 커밋하고 여행별 최근 100건을 보관한다.
