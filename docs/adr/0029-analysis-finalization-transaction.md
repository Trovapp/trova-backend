# 0029 분석 결과 교체와 완료를 하나의 트랜잭션으로 저장한다

- 상태: 확정 · 날짜: 2026-11-01 · 관련: #292, ADR0024 보완

## 결정

외부 추출·지오코딩·선별을 끝낸 뒤 `completeAnalysis`에서 작업 행을 잠그고 PROCESSING/미완료 상태를 재확인한다. 이전 버전이 남긴 미완료 부분 장소는 같은 트랜잭션에서 교체하고 새 장소 전체와 분석 DONE을 함께 커밋한다. 중간 저장 실패는 삭제·새 행·완료 상태를 모두 롤백한다. 완료/실패/일정 생성 중인 결과는 덮지 않는다.

기존 단일 JVM 작업 잠금과 시작/큐/재시도 정책은 유지한다. 외부 호출 동안 DB 잠금을 잡지 않는다. 기존 단일 행 저장 메서드는 호환/복구 fixture용으로 남기되 실제 영상 분석 경로는 전체 완료 메서드만 사용한다.

## 범위

ADR0024의 실행 직렬화 결정을 유지하면서 부분 저장의 일관성을 추가로 다룬다. 완료된 사용자 결과를 일괄 삭제하지 않으며 운영의 과거 부분 결과를 별도 정리하지 않는다. 기존 미완료 작업이 정상 재수신·완료될 때만 교체한다. 다중 JVM 분석 선점/외부 호출 exactly-once나 Kafka 보존 보장은 아니다. TripPlace의 원본 SavedPlace 추적 ID는 FK가 아니며, 미완료 부분 결과 교체 시 과거 ID를 유지하지 않는다.
