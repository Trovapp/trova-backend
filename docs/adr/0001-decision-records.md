# 0001 결정 기록·작업 기록·지침의 역할 나누기
- 상태: 확정 · 날짜: 2026-10-08 · 근거: 이슈 #143, SDD(명세 주도 개발) 검토

## 결정
- 결정은 `docs/adr/`, 작업 결과는 `docs/experience-notes.md`, 지켜야 할 규칙 요약은 `CLAUDE.md`에 둔다.
- `CLAUDE.md`는 내용을 반복하지 않고 ADR·작업 기록을 가리킨다.

## 이유
- 결정이 CLAUDE.md(STT 배경), 작업 기록, 대화 메모 등에 흩어져 있어서, 같은 질문을 다시 하거나(좌표 없는 장소 정책은 8/24 보류 → 9/28 다시 물어 확정) 모르고 뒤집을 위험이 있었다.
- SDD 정리에서 "결정 기록(ADR)"과 "작업 기록(LLM Wiki)"이 둘 다 지식베이스라 헷갈린다는 지적이 있어, 처음부터 역할을 나눈다.

## 비교한 대안
- 작업 기록 하나에 결정까지 쓰기: 이미 1,000줄 가까이 돼 결정을 찾기 어렵다.
- CLAUDE.md에 모두 쓰기: 매 세션 읽히는 파일이라 길어질수록 비용이 들고, git에 올라가지 않는다(.gitignore).

## 다시 볼 조건
- 문서가 세 곳이라 갱신을 빠뜨리는 일이 반복되면 합치는 것을 다시 검토한다.
