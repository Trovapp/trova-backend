# 0031 명시된 비장소 이름은 좁은 출력 점검으로 제외한다

- 상태: 확정 · 날짜: 2026-11-01 · 관련: #293, ADR0022

## 결정

기존 FILTER_PROMPT가 제외하는 넓은 지역명(서울/부산/제주도와 명시적 영문 표기) 및 고정 지도 지점이 아닌 열차/차량 내부 표기를 정확 일치로 점검한다. 부분 문자열로 다른 지점을 지우지 않으며, 업종이나 구체적 주소가 있는 같은 이름의 실제 가게는 보존한다. 특정 영상의 정답 상호/검증되지 않은 별칭을 코드에 넣지 않는다.

실제 전후10사례에서 후보 grounding 프롬프트는 strict precision/recall이 모두 하락하고 정답 없는 영상의 오탐이 늘어 채택하지 않는다. 기존 프롬프트/모델/미디어 경로/호출수는 유지한다. 이 출력 점검의 효과는 별도 제한된 사례와 운영 서버 추출 부분의 재생으로 확인하며 전체 서비스 정확도 개선률을 주장하지 않는다.

## 한계

도시와 같은 이름의 가게에 구체적 주소/업종 근거가 있으면 자동 제외하지 않는다. 문맥을 알 수 없는 전세계 지명/별칭을 추측해 광범위하게 지우지 않는다. 누락·철자 오류 전부를 해결한 것은 아니다. 원래 응답의 다른 필드/객체/순서는 보존한다. 채점과 사람 정답은 바꾸지 않는다.
