# 0027 같은 장소의 진행 중 상세 생성은 한 JVM에서 공유한다

- 상태: 확정 · 날짜: 2026-10-31 · 관련: #276, #267 후속 검토, 사용자 세 항목 수정 승인

## 결정
PlaceReviewService에서 placeId별 진행 Future를 등록해 동일 JVM의 동시 상세/요약/전화 조회를 한 번만 실행한다. 대기자는 성공·fallback·예외를 공유하며, 대기자의 인터럽트는 소유 작업을 취소하지 않는다. 완료/실패 시 소유 항목을 제거한다.

기존 DB 캐시가 있으면 그대로 읽고, 실패 fallback은 영구 저장하지 않는다. 따라서 완료 뒤의 독립된 요청은 기존 정책대로 재시도할 수 있다. 요청별 API 한도 계산이나 외부 클라이언트의 내부 재시도는 바꾸지 않는다. DB 트랜잭션을 외부 호출 전체에 걸쳐 유지하지 않는다.

## 범위
한 인스턴스의 동시 중복을 줄이는 구현이다. 서로 다른 장소는 기다리지 않으며, 다중 JVM의 중복 호출이나 프로세스 종료 후 외부 호출 exactly-once는 보장하지 않는다. 새 API/의존성/스키마 변경은 없다.
