# 0013. 앱스토어 전에는 앱(Expo) 웹 버전을 PWA로 배포하고, 아이폰 링크 넣기는 단축어로

- 상태: 확정
- 날짜: 2026-10-12
- 관련: 백엔드 #165, Trovapp/trova-app#7, 설계 [2026-10-12-pwa-design.md](../superpowers/specs/2026-10-12-pwa-design.md)

## 결정
- 앱스토어·애플 개발자 계정(연 $99) 없이 쓰게 하는 첫 배포는 PWA(홈 화면에 추가하는 웹앱)로 한다. 바탕은 지금 앱(Expo) 코드의 웹 내보내기이고, 웹에서 안 되는 부분만 웹용 파일로 바꾼다. Cloudflare Pages(무료)에 올린다.
- 브라우저로 열면 소개 → 설치 안내(그림)로 유도하고, 홈 화면 아이콘으로 열면 앱 화면을 바로 보여준다.
- 링크 넣기: 안드로이드는 PWA 공유 목록(Web Share Target), 아이폰은 iOS 단축어 "Trova에 저장" + 공유만 할 수 있는 사용자별 공유 전용 키, 공통으로 복사한 링크 붙여넣기 버튼.
- 웹 로그인은 관리자 웹과 같은 1회용 코드 교환으로 하고 쿠키를 쓰지 않는다.

## 이유
- 아이폰은 웹에서 받은 앱 파일을 설치할 수 없다. TestFlight도 개발자 계정이 필요하다. 0원으로 아이폰 사용자에게 닿는 길은 PWA뿐이다(비용 0원 원칙, [0002](0002-cost-zero-free-tiers.md)).
- 웹 앱(trova-frontend)은 2026-08 이후 멈춰 최신 기능(자동 일정·재구성 등)이 없다. 앱 코드를 웹으로 내보내면 코드 하나로 앱·PWA를 함께 유지한다. 2026-10-12 시험 빌드에서 웹 실행을 확인했다.
- 아이폰 PWA는 공유 목록에 뜨지 않는다(Web Share Target 미지원). 단축어는 공유 목록에 뜨고 개발자 계정이 필요 없어, "공유 한 번"에 가장 가깝다. 단축어가 쓰는 키는 공유 저장만 되게 범위를 좁혀 새도 피해를 줄인다.
- Vercel 무료 플랜은 상업적 사용을 막아 수익 모델([0007](0007-travel-pass-bm.md))과 부딪힌다. 관리자 웹([0012](0012-admin-dashboard-web.md))과 같이 Cloudflare Pages를 쓴다.

## 검토한 다른 방법
1. TestFlight 공개 링크 — 가장 앱다운 경험이지만 연 $99, 빌드 90일 만료.
2. 기존 웹 앱(trova-frontend)을 PWA로 — 최신 기능을 다시 만들어야 하고 앱·웹 두 곳을 고쳐야 한다.
3. 카카오톡 채널 챗봇으로 링크 받기 — 익숙한 흐름이지만 계정 연결·챗봇 서버가 크고 무료 범위를 확인하지 못했다.
4. 안드로이드 APK 링크 — 안드로이드만 해결되고 설치 경고가 크다. 필요하면 나중에 더한다.

## 결과
- 아이폰 사용자는 단축어를 한 번 설치(키 붙여넣기)해야 "공유 → Trova에 저장"이 된다. 설치하지 않으면 복사한 링크 붙여넣기.
- 웹 푸시 알림·오프라인은 이번에 하지 않는다. 사용자가 늘면 앱스토어 출시(같은 Expo 코드)로 넘어간다.
- 카카오 지도는 웹 도메인을 카카오 개발자 콘솔에 등록해야 웹에서 뜬다.
