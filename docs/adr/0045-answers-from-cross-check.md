# 0045. 장소 추출 정답에 Gemini·GPT 교차 일치분과 판정분을 넣는다 (0022의 "AI 출력을 정답으로 넣지 않는다"를 바꿈)

- 상태: 확정 · 날짜: 2026-11-16 · 근거: 이슈 #437(사용자 작성, "일치하면 정답으로 넣고 불일치만 사람이 본다"), 사용자 지시 2026-11-16("answers.csv 반영 — 일치분과 Y 행 추가"), PR #442 리뷰
- 관련: [0022](0022-pipeline-regression-eval-evalflow.md)(정답은 answers.csv 한 곳, AI 출력을 정답으로 넣지 않음 — 이 부분만 바뀜), 기록 `docs/eval/cross-check-20261116.md`

## 배경
`eval/extraction/answers.csv`는 사람이 영상을 보고 직접 적은 127행(영상 24개)이었다. 0022와 `eval/README.md` Part A는
"영상을 보고 직접, AI 결과를 보지 않고" 적도록 했다. 300행 이상으로 늘리려면 영상 200개를 사람이 다 보기 어렵다.

## 결정
- 같은 영상을 Gemini와 GPT에 따로 넣는다. 입력은 같지 않다: **Gemini(파이프라인 `extract_places`)는 오디오 포함**
  (제목·설명·자막·오디오·프레임 8장), **GPT(Codex)는 제목·설명·한국어 자막·프레임 8장**(Codex에 오디오를 넘길 수 없음).
  **둘이 같은 장소를 내면 정답 후보**로 본다.
- 하나만 낸 장소는 판정한 것(Y)만 넣는다. **판정은 Claude가 초안(Y/N/?)을 만들고, 사용자가 기준과 "?" 행을 확정**했다.
  기준은 기존 정답과 같다: **영상이 소개한 장소만**(주변·해시태그·목록에 언급만, 다른 장소 안 시설, 번화가·상권·체인 지점 불명은 정답 아님).
  교차 일치여도 사람이 N으로 판정한 장소는 넣지 않는다(c072 하조대 등대).
- 새 행은 `note`에 출처를 남긴다. 사람이 직접 적은 기존 행(note 비었거나 다른 내용)과 구분된다.
  - `#437 <샘플> 교차 일치(Gemini=…, GPT=…)` — 둘이 같이 낸 장소
  - `#437 <샘플> 판정 Y(사용자, …)` — 사용자가 직접 Y로 정한 행
  - `#437 <샘플> 판정 Y(초안 Claude·기준 사용자, …)` — Claude 초안이 사용자가 정한 기준으로 Y였고 사용자가 따로 보지 않은 행
  - `#437 <샘플> 장소 안 나옴(…)` — 정답이 하나도 남지 않은 영상(기존 방식대로 빈 `place_name`)
- 새 영상 번호는 1000 + 샘플 번호(c007 → 1007)로 기존 1~35와 섞이지 않게 한다. `videos.csv`에는 `selected`를 비워 넣는다.
  Part A·evalflow 측정 범위(`selected=Y`)에 넣을지는 따로 정한다.
- 0022의 나머지(정답은 answers.csv 한 곳, evalflow 기대값은 `build_config.py`가 생성)는 그대로다.

## 비교한 대안
- **로컬 Whisper로 GPT에도 자막을 만들어 주기**: 입력 차이(오디오)를 줄이지만 셀프호스팅 STT를 쓰지 않기로 한 결정(0004)과
  어긋나고 영상 200개 처리 시간이 든다. 자막 없는 영상에서 GPT가 덜 내는 것은 불일치 판정으로 보완했다.
- **일치분도 사람이 전부 훑기**: 가장 정확하지만 554행을 다 보는 데 드는 시간이 이슈의 목적(사람은 불일치만 본다)과 맞지 않는다.
- **AI 출력을 정답에 넣지 않는 0022 유지**: 정답이 127행(영상 24개)에 머물러 측정 오차가 크다. 300행 이상이 이슈 완료 조건이다.

## 결과와 한계
- 교차 일치분의 정확도는 사람이 전부 보지 않았다. GPT를 사람 정답과 비교한 정밀도가 79.8%였고, 둘이 같이 틀릴 수 있다.
- 표기는 교차 판정에서 확인한 것만 고쳤다(기록 7절·8절). 나머지는 Gemini 표기 그대로다.

## 다시 볼 조건
- Gemini 모델·프롬프트를 바꿔 evalflow 전후를 비교할 때: 교차 일치 행(`note`가 `교차 일치`)은 Gemini 자신의 출력이 반쯤
  섞여 있어 기존 Gemini 쪽에 유리할 수 있다. 사람이 적은 행과 나눠 점수를 보고, 차이가 크면 교차 일치 행을 다시 검증한다.
- 측정에서 이상한 오답(정답인데 틀렸다고 나오는 것)이 교차 일치·판정 행에서 나올 때: `note`로 출처를 보고 그 행을 다시 판정한다.
