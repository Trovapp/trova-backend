# 0006 좌표 없는 장소는 목록에 남기고 "위치 확인 안됨" 표시
- 상태: 확정 · 날짜: 2026-09-28 · 근거: 사용자 결정(8/24 보류 후 QA 데이터 점검 중 확정)

## 결정
지오코딩(카카오 검색)이 실패해 좌표가 없는 장소도 일정·목록에 그대로 남기고, "위치 확인 안됨 · 지도에 안 뜰 수 있어요"를 표시한다. 지도에서는 좌표 없는 핀만 뺀다.

## 비교한 대안
1. 숨기기 2. 저장하지 않기 3. 표시하고 남기기(선택) 4. 사용자가 직접 정리

## 이유
- 영상에서 말한 장소는 좌표가 없어도 사용자에게 의미가 있다. 숨기거나 버리면 영상 내용이 사라진다.

## 다시 볼 조건
- 좌표 없는 장소를 숨기거나 저장하지 않는 변경은 이 결정과 부딪힌다 — 먼저 사용자에게 결정을 바꿀지 묻는다.
