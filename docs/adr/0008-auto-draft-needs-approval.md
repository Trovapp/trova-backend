# 0008 공유하면 일정 초안까지만 자동, 여행은 승인 후
- 상태: 확정 · 날짜: 2026-10-07 · 근거: 이슈 #136, `docs/superpowers/specs/2026-10-07-auto-draft-and-push-design.md`

## 결정
- 영상 분석이 끝나면 그 영상으로 일정 **초안**을 자동으로 만든다. 여행은 사용자가 확인·승인해야 만들어진다.
- 기간은 영상 기준: 장소의 일차 구분 → 제목의 "N박 M일" → 당일치기.
- 같은 영상의 자동 초안은 닫은 것까지 포함해 다시 만들지 않는다.

## 이유
- 제품 방향은 "공유 한 번 → 열면 일정이 있음"이다. 다만 원하지 않는 여행이 쌓이지 않게 마지막 확인은 사람이 한다.

## 비교한 대안
- 여행까지 자동 생성: 목록이 원치 않는 여행으로 채워진다.

## 다시 볼 조건
- 자동 초안을 승인하는 비율이 매우 높으면 여행까지 자동으로 만드는 것을 검토한다.
