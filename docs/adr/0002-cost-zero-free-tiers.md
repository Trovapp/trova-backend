# 0002 API 비용 0원, 무료 티어 + 재시도
- 상태: 확정 · 날짜: 2026-08(프로젝트 시작) · 근거: CLAUDE.md "비용 원칙"

## 결정
- 외부 API는 무료 티어 안에서 쓴다. 유료 API(OpenAI Whisper API, Claude API 등)를 기본값으로 두지 않는다.
- 새 외부 서비스는 무료 티어가 있는지 먼저 확인한다.
- 무료 티어의 요청 제한은 코드에 반영한다(지수 백오프·재시도).
- 쓰는 것: Gemini API 무료 티어(장소 추출·STT), 카카오 로컬 API(일 10만 / 월 300만 건), yt-dlp, Supabase(Postgres), Oracle Cloud Always Free.

## 이유
- 개인 프로젝트로 검증 단계에서 고정 비용 없이 오래 운영하기 위해서.

## 비교한 대안
- 유료 API로 품질·속도를 먼저 확보: 검증 전 단계에서 비용 위험이 크다.

## 다시 볼 조건
- 수익 모델([0007](0007-travel-pass-bm.md))이 실제로 반영되면 Gemini 유료 등급을 검토한다.
- 참고: 로컬과 운영이 같은 Gemini 키(같은 하루 한도)를 쓴다. 2026-10-04 로컬 측정이 한도를 다 써 운영 분석까지 막혔다 — Gemini를 부르는 측정 전에는 오늘 사용량부터 확인한다.
