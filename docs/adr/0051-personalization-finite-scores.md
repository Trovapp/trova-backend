# 0051 개인화는 유한한 유사도만 평균하고 무효 최종 점수는 뒤로 정렬한다

- 상태: 확정 · 날짜: 2026-11-19 · 근거: #487, PR #483 재검증

## 결정

단건·묶음 개인화는 기존 top-5 결과의 유한 유사도만 순서를 보존하여 평균한다. 남는 신호가 없으면 0점이며, 추천 이유에도 무효 신호를 쓰지 않는다. 빈 시간·대안 추천의 비유한 최종 점수는 모든 유한 후보 뒤로 보낸다. 유한 후보의 기존 점수 순서·동점 순서 및 대안의 기본 검색 우선순위는 유지한다.

Google types가 없으면 카탈로그의 null 분류를 유지한다. 빈 시간 추천은 대안 추천과 같이 분류가 있는 후보만 제외 목록에 대조한다.

채팅의 대안 찾기(`find_alternatives`)와 빈 시간 추천(`get_gap_recommendations`)이 공유하는 요청 문장 재정렬에도 비유한 최종 점수 후순위 정책을 적용한다. 유한 점수의 기존 가중합·내림차순·동점 순서는 유지하며, 무효 후보끼리는 입력 순서를 보존한다. 0 벡터 query로 모든 유사도가 NaN이면 후보 전체의 원래 순서를 유지한다.

## 이유와 비교한 대안

0 벡터 cosine은 NaN이고 역순 comparingDouble은 이를 유한 값보다 앞에 둔다. 무효 유사도를 0점으로 평균에 넣으면 정상 신호까지 희석된다. 신호 제외는 유효한 근거만 쓰며 기존 콜드스타트 폴백과도 맞는다. types 누락을 임의 분류나 후보 삭제로 처리할 근거는 없고, 기존 카탈로그·대안 추천은 null을 허용한다.

## 확인 방법

서비스 회귀 테스트로 NaN 후순위·유한 점수 및 동점 순서·단건/묶음 평균을 검증하고, HTTP 테스트로 types 누락 포함 시 200과 null 분류 보존을 확인한다. pgvector 동일성 테스트는 원시 top-5와 유한 점수의 비트 동일성, 0 벡터의 0점 폴백을 확인한다.

채팅의 두 도구 경로에서 혼합된 NaN·무한대 후순위, 유한 점수·동점 순서, 누락 유사도의 기존 0점 처리와 전부 NaN일 때 원래 순서를 검증한다. 0 벡터 임베딩과 NaN 조회 결과를 사용하는 `queryScores` 연결 테스트도 포함한다.

## 다시 볼 조건

신호 검색 top-5 자체를 바꾸거나 대안 기본/보충 검색 우선 정책을 바꿀 때 재검토한다. SQL 검색 범위나 요청 문장 기반 queryScores의 원시 유사도는 변경하지 않으며, 채팅에서는 이를 소비하는 최종 정렬에만 후순위 정책을 적용한다.
