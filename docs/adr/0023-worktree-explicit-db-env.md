# 0023. 워크트리 루트 DB 환경은 명시적으로 준비한다

- 상태: 확정
- 날짜: 2026-10-31
- 관련: #257, PR #259

## 배경
메인 체크아웃의 루트 `.env`가 운영 DB를 가리킨 채 새 워크트리에 자동 복사됐다. 해당 폴더에서 서버를 실행하면 JPA의 스키마 갱신이 운영에 적용될 수 있다.

## 결정
- `.worktreeinclude`에서 루트 `.env` 자동 복사를 제외한다.
- 서버 실행 전 개발 DB용 환경을 명시적으로 준비하고 대상 DB를 확인한다. 메인 체크아웃 환경을 무조건 복사하지 않는다.
- 운영 점검·배포 도구는 지정된 운영 환경 파일 경로를 명시적으로 읽는다.
- 기존 환경 파일과 실행 중 서버는 변경하지 않는다. `pipeline-test/.env`는 DB 연결 정보가 필요 없는 파이프라인 평가용으로 계속 복사한다.

## 한계
이미 생성된 워크트리의 `.env`는 남아 있다. 자동 복사 제외는 새 워크트리의 오접속 방지이며 기존 파일을 개발 DB로 전환하는 조치는 아니다.
