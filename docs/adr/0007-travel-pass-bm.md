# 0007 수익 모델: 무료 + 여행 패스
- 상태: 대기(브랜치·PR만 있고 머지·배포하지 않음) · 날짜: 2026-10-05 · 근거: 사용자 결정, PR #131·#133

## 결정
- 모으기(영상 저장·지도·찜·여행 만들기)는 무료, 계획·AI는 여행 패스(30일 4,900원, 자동 갱신 아님).
- 무료(월): 분석 20 / AI 초안 1 / 비서·대안·재구성 5. 패스: 분석 월 100 / 초안 하루 10 / 비서 등 하루 30.
- 자동으로 만든 일정 초안([0008](0008-auto-draft-needs-approval.md))은 이용 횟수에 세지 않는다.

## 이유
- 영상 분석 원가 약 8원, 여행 하나당 최악 약 2,200원(대부분 영업시간 확인). 여행은 띄엄띄엄 하므로 월 구독보다 여행 단위 패스가 맞다.

## 다시 볼 조건
- 사용자가 머지·배포를 지시할 때(Apple 개발자 등록, 사업자등록·통신판매업 신고, 상품 등록, 서버 영수증 검증이 먼저 필요).
