## 2. 막힌 것 — WSL의 Gemini 키가 거부됨

- [실측] `bash -l`에서 잡히는 `GEMINI_API_KEY`로 호출하면 `401 UNAUTHENTICATED`, `API key not valid`, 이유 `ACCESS_TOKEN_TYPE_UNSUPPORTED`. 값이 AI Studio API 키 형식이 아니다(값은 출력하지 않고 길이·접두어만 확인).
- 사용량: 401이라 생성 요청은 처리되지 않았다. 시도 횟수는 영상 5개 × 1번 + 확인용 2번.
- 처음 5번은 `bash`(로그인 셸 아님)로 돌려 키가 아예 없었고, 이때는 Gemini 호출 자체가 없었다.
- 이 워크트리에는 `pipeline-test/.env`가 없다(`.worktreeinclude` 복사 안 됨). `load_api_key`는 환경 변수를 먼저 보므로 `.env`를 만들어도 로그인 셸의 잘못된 변수가 우선한다.
- 해결안(사용자 확인 필요): ① WSL 로그인 프로필의 `GEMINI_API_KEY`를 운영과 같은 AI Studio 키로 바꾼다, 또는 ② 이 워크트리 `pipeline-test/.env`에 키를 넣고 `env -u GEMINI_API_KEY python3 ...`로 돌린다.

## 3. GPT 판정자 점검 — 사람 정답과 비교 [실측]

`score-human`: `answers.csv`(is_destination=Y)와 GPT 결과를 교차 판정과 같은 이름 맞추기로 비교. 영상 24개 중 행이 생긴 22개.

| 지표 | 값 |
|---|---|
| 사람 정답 장소 | 122 |
| GPT가 낸 장소 | 89 |
| 일치 | 70 |
| 재현율(정답 중 GPT가 찾은 비율) | **57.4%** |
| 정밀도(GPT 중 정답인 비율) | **78.7%** |

놓친 이유(`human_compare.csv`를 직접 읽어 분류):
- **오디오를 못 받음**: 자막 없는 영상에서 프레임 8장에 이름이 안 보이면 GPT는 찾을 수 없다. 예: v008(자막 없음, 정답 24개 중 GPT 8개), v012(자막 없음, 11개 중 4개). 자막이 있어도 장소가 많으면 놓친다: v011(11개 중 3개).
- **표기 차이로 짝이 안 됨**: `김녕해수욕장`/`김영 해수욕장`, `세화해수욕장`/`새화 해수욕장`, `ARTNINE`/`아트나인&잇나인`. 같은 곳인데 이름 유사도(0.85 기준)를 넘지 못했다. 이런 건은 불일치 목록에서 사람이 바로 고를 수 있다.
- **정답에 없는 것**: 지역 축제(`해운대모래축제`)나 전망대처럼 정답 기준에서 뺀 것.

판단:
- 정밀도 78.7%라 **둘 다 낸 장소를 정답 후보로 쓰는 방식은 유지할 만하다.** 다만 일치한 것도 사람이 한 번 훑는 것을 권장한다(두 모델이 같은 오인식을 할 수 있음).
- 재현율 57.4%라 **GPT가 못 찾은 Gemini 결과(gemini_only)가 많이 생길 것이다.** [추정] 30개 기준 불일치 50~80건이 사람 확인으로 넘어간다.
- 개선안(아침 결정): GPT에도 말소리를 주려면 자막이 필요하다. ① 유튜브 자막을 영어 번역 없이 받는 지금 방식 유지(자막 있는 영상 절반) ② Windows 노트북에서 로컬 Whisper로 평가용 자막만 만들어 GPT에 넣기(무료, 운영 STT 방식(ADR 0004)과는 별개) ③ 그대로 두고 불일치를 사람이 보기.
