# Trova 홍보 브리프

## 한 줄 설명

글자 수는 공백과 문장부호를 포함해 제한 안으로 작성했어요.

| 길이 | 문구 |
|---|---|
| 10자 이내 | 여행 릴스를 지도에 |
| 30자 이내 | 여행 영상 공유하면 장소와 일정 초안이 생겨요 |
| 80자 이내 | 저장한 여행 릴스·쇼츠를 공유해 보세요. AI가 장소를 지도에 담고, 영상 속 팁과 하루 일정 초안까지 정리해요. |

## 누구에게 말하나요

저장만 해 둔 여행 릴스·쇼츠가 쌓인 사람이 써요. 여행을 앞두고 저장 목록을 다시 열었지만, 어디부터 정리할지 막막한 순간에 말을 걸어요.

- 장소 이름을 찾으려고 영상을 멈추고 되돌려 봐요.
- 영상과 댓글에서 찾은 장소를 지도 앱에 하나씩 검색해 옮겨요.
- 여러 영상의 장소와 팁이 흩어져 있어 하루에 어디부터 갈지 정하기 어려워요.

## 소개할 때 지킬 사실

- 인스타 릴스·유튜브 쇼츠를 공유하면 AI가 영상 속 장소를 추출해 지도에 담고 하루 일정 초안을 만들어요.
- 장소마다 영상에서 말한 팁을 메모로 붙여요. 리뷰는 좋은 점·아쉬운 점으로 요약하고, 휴무일·영업시간 미확인 경고도 보여 줘요.
- AI가 장소를 놓치거나 잘못 찾을 수 있어요. 일정은 확인하고 다듬을 초안이에요. 방문 전 위치와 운영 정보를 확인하도록 안내해요.
- 아이폰은 PWA를 홈 화면에 추가하고 공유 단축어를 연결해요. 안드로이드는 네이티브 앱이며 플레이 스토어 비공개 테스트 중이에요. 누구나 스토어에서 바로 설치할 수 있다고 안내하지 않아요.
- 무료로 쓰는 앱이고, 혼자 개발하고 있어요. 운영은 무료 티어를 활용한다고만 설명해요.
- 시작 안내: https://trovapp.github.io/start/ · 문의: trovapp26@gmail.com

## 톤 가이드

해요체로 써요. 한 문장에는 한 가지를 담아요. 기능 이름보다 손으로 하던 일을 먼저 말해요. 실제 화면에서 확인한 결과만 설명하고, 아직 모르면 모른다고 적어요. 이모지는 꼭 필요할 때만 써요.

**쓸 수 있는 문장**

- “저장한 여행 릴스, 어디였는지 다시 찾고 있나요?”
- “공유하면 AI가 찾은 장소를 지도에 담아 줘요.”
- “영상에서 말한 팁도 장소 메모에서 다시 볼 수 있어요.”
- “AI가 장소를 잘못 찾을 수 있어요. 방문 전에 확인해 주세요.”
- “혼자 만들고 있어요. 불편했던 장면을 알려 주시면 확인해 볼게요.”

**피해야 할 문장**

- “여행 준비가 무조건 끝나요.” — 일정 초안과 확인할 일이 남아 있어요.
- “영상 속 장소를 빠짐없이 정확하게 찾아요.” — AI의 누락과 오인식을 숨겨요.
- “공유하자마자 바로 완성돼요.” — 실제 분석 대기를 지워요.
- “휴무일과 영업시간은 확인할 필요 없어요.” — 미확인 정보가 있을 수 있어요.
- “안드로이드는 누구나 플레이 스토어에서 바로 설치해요.” — 비공개 테스트 상태와 달라요.
