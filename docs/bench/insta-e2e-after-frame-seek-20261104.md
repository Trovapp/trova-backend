# 프레임 뽑기 변경(#323) 뒤 인스타 분석 1건 전체 시간 (#325)

**운영 서버(Oracle E2.1.Micro)에서 테스트 계정(user 1)으로 인스타 1건(작업 132)을 분석했다.** 운영 코드는 main `443ae25`(JAR `a8c04d0` + Python 5개 main과 해시 일치)다. 같은 영상(DX-rrm8BHCr, 46초)을 #319에서 두 번 분석한 값(작업 129·131)과 비교한다. 1건뿐이라 다운로드·Gemini 흔들림이 섞여 있다.

- 원본: [작업 132](results/insta-e2e-after-frame-seek-20261104.json), [메모리 비교](results/frame-seek-memory-prod-20261104.json), 도구 [production_resource_sample.py](scripts/production_resource_sample.py) `--kinds instagram`
- 테스트로 생긴 장소 1개·자동 초안 1개는 백업(0600) 후 지웠고 작업·API 기록은 남겼다. Gemini 2회(collect·filter)를 썼다.

## 분석 1건

| 작업 | 코드 | 분석 실행 | download | audio | **frames** | gemini | 자식 CPU | 가장 큰 자식 메모리 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 129 | 예전 | 40.922초 | 10.8초 | 1.2초 | 19.6초 | 7.7초 | 37,557ms | 72.5MiB |
| 131 | 예전 | 36.987초 | 8.2초 | 1.3초 | 19.7초 | 6.1초 | 38,239ms | 72.6MiB |
| **132** | **#323** | **32.219초** | 8.9초 | 1.1초 | **12.6초** | 7.1초 | 25,824ms | **217.5MiB** |

- 프레임 단계가 약 7초 줄었고 분석 1건은 37.0~40.9초 → 32.2초다. 줄어든 몫은 거의 프레임 단계에서 나왔다(다운로드·Gemini는 이전 범위 안).
- **메모리가 늘었다.** 새 방식은 ffmpeg 하나에 같은 영상을 입력 8개로 열어 디코더 8개가 동시에 떠 있다. 서버 전체가 956MB(측정 시 사용 가능 395MB, 스왑 556MB 사용 중)라 무시할 수 없다.

## 메모리를 줄이는 변형 (운영 서버, 임시 폴더, 같은 영상)

운영 파일은 바꾸지 않고 서버 임시 복사본에서만 시험했다. 진행 중 분석 0건을 확인했고 `nice -n 10`으로 돌렸다.

| 변형 | 시간(중앙값) | 자식 CPU | 가장 큰 자식 메모리 | 횟수 |
|---|---:|---:|---:|---:|
| 예전(전체 디코딩) | 20.1초 | 33.3초 | 72.5MiB | 3 |
| 현재 main(입력 8개 동시) | 12.0초 | 19.2초 | 217.6MiB | 6 |
| 입력마다 `-threads 1`, 8개 한 번에 | 9.0초 | 8.9초 | 164.8MiB | 5 |
| `-threads 1`, 4개씩 2번 | 9.2초 | 9.1초 | 106.7MiB | 2 |
| `-threads 1`, 2개씩 4번 | 9.5초 | 9.5초 | 80.2MiB | 2 |

- 2코어 서버에서 디코더 8개가 각자 스레드를 여러 개 띄우면 서로 CPU를 빼앗는다. 한 스레드로 묶으니 **오히려 빨라지고 CPU가 절반**이 됐다.
- 2개씩 나누면 메모리가 예전과 비슷해지고(80MiB), 시간은 예전 20초 대비 9.5초다.
- `-threads 1, 2개씩` 결과 JPEG 8장은 현재 main 결과와 md5가 모두 같다(같은 장면, 같은 바이트).

## 반영 (#327)

`-threads 1`, 2개씩(`SEEK_INPUTS_PER_CALL = 2`)을 코드에 넣고 운영 임시 폴더에서 운영 파일과 번갈아 3회씩 다시 쟀다([원본](results/frame-seek-threads-prod-20261104.json)).

| | 시간(중앙값) | 자식 CPU | 가장 큰 자식 메모리 |
|---|---:|---:|---:|
| 반영 전(main 443ae25) | 11.97초 | 18.7초 | 218.0MiB |
| 반영 후 | **9.46초** | **9.4초** | **80.4MiB** |

결과 JPEG 8장 md5가 모두 같고, 서버에서 테스트 7개가 통과했다.
