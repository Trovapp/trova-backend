## 원인
1. **조회 100명은 이 서버에 과하다.** r25(11-11)는 조회만 200명까지 오류 0.5%였지만 그때는 분석이 없었고 서버가 따뜻했다. 조회 100명 + 분석 1개가 겹치자 CPU 100%(1/8 OCPU)와
   java 힙 밖 메모리 +120MiB가 동시에 왔고, `MemorySwapMax=0`이라 java는 못 밀려나고 나머지(Caddy·sshd·파이썬)가 스왑으로 밀려 서버 전체가 멈췄다.
2. **배포 직후 시작.** JIT·코드 캐시·스레드 풀이 막 커지는 시점이라 힙 밖 메모리 증가가 평소보다 컸을 가능성(422 → 541MiB). r26은 2시간 뒤였다.
3. SSH 터널은 서버가 멈추자 함께 끊겨(sshd도 밀림) 부하 생성기가 "연결 거부"로 바뀌었다. 측정 경로로 터널은 부적합하다.
