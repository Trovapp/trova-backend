# 공동 편집 현장 기록 (서버 대조 전)

이 문서는 화면 관찰 메모이며 HTTP 응답 코드를 확정하지 않는다. 각 시도의 정확한 호스트 입력 시각과 캡처 구간은 `observations/<시도>/timing.json`에 있다.

## 메모 10회

`memo-01`~`memo-10`: 6번은 A, 나머지 9번은 B의 메모가 양쪽 저장값에 표시됨. 패한 쪽은 친구가 방금 바꿨다는 안내와 자기 입력을 유지함. 입력이 안내 없이 사라지는 사례는 이 10회에서 관찰하지 못함.

## 순서 10회

기호: T=이삭토스트 명동성당점, L=연화정 도서관, B=광안리해수욕장.

| 시도 | 양쪽 최종 순서 |
|---|---|
| 01 | T,B,L |
| 02 | T,L,B |
| 03 | L,T,B |
| 04 | T,L,B |
| 05 | T,B,L |
| 06 | T,L,B |
| 07 | T,B,L |
| 08 | T,L,B |
| 09 | T,B,L |
| 10 | T,L,B |

이동 방향은 03·04에서 A 아래/B 위, 나머지는 A 위/B 아래. 순서 실험 동안 A에 남아 있던 메모 충돌 안내는 순서 충돌의 새 안내로 세지 않는다.

## 삭제와 메모 10회

A는 토스트 메모 저장, B는 같은 토스트 삭제 확인. 05·08에서 A 메모가 저장되고 양쪽에 장소가 남음. 01·02·03·04·06·07·09·10에서 양쪽 장소가 사라짐. 삭제 성공 후 B의 기존 저장 목록에서 같은 장소를 다시 추가해 다음 시도를 준비했고, 각 준비는 본 측정에서 제외함.

## 오프라인 10회

A 비행기 모드 켜기와 Wi-Fi 끄기를 함께 적용. A에서 오프라인 입력, B는 온라인에서 다른 값 입력, 양쪽 저장 시도 후 10초 관찰. A 비행기 모드 끄기와 Wi-Fi 복구 후 1·3·6·10·20초 관찰. 자동 재전송을 위한 추가 조작 없음. 그 뒤 별도 수동 저장 재시도.

- 01: 실제 A 입력은 `-offline-01`(포커스 전환 중 첫 글자 누락), B는 `B-offline-01`. 20초 복구 관찰까지 A의 네트워크 오류와 입력이 남고 B 값은 안 보임. 수동 재시도 뒤 B 값과 충돌 안내, A 입력 유지.
- 02: 저장 시작 실패 안내, 복구 20초까지 이전 B 값과 A 입력 유지. 수동 재시도 뒤 최신 B 값과 충돌 안내, A 입력 유지.
- 03: 네트워크 확인 안내, 복구 20초까지 이전 B 값과 A 입력 유지. 수동 재시도 뒤 최신 B 값과 충돌 안내, A 입력 유지.
- 04~09: 03과 같은 양상. 각 reconnect-20s와 retry-5584 원본 보관.
- 10: 복구 20초뿐 아니라 40·60초에도 이전 `B-offline-09`와 A 입력·네트워크 오류 유지. 수동 재시도 뒤 `B-offline-10`과 충돌 안내, A 입력 유지.

20초 내 자동 수렴 0/10, 연결 복구 뒤 수동 저장 재시도로 최신 값과 충돌 안내 확인 10/10. 이는 이 장시간 열린 화면에서의 관찰이며 원인은 서버 SSE 응답·연결 수 기록과 대조 전까지 단정하지 않는다. 실제 원인에는 연결 상한, 연결 종료 감지 지연, 클라이언트 재연결 처리 등이 후보로 남는다.

## 종료·정리

측정 종료 기록 17:08:11 KST. B의 여행 삭제 확인 화면에서 `V11-CONFLICT-533`만 삭제했고 17:09 이전 B가 여행 목록으로 돌아온 화면을 확인했다. A는 비행기 모드 0·Wi-Fi 1로 복구 확인. 정리 캡처는 cleanup 폴더에 보관.

사전 빌드 성공: 1489 tests, failures 0, errors 0, skipped 22. 빌드는 16:08:39 종료해 측정과 겹치지 않음.

## 준비 오류·해석 한계

- memo-07 준비 중 잘못된 좌표로 도서관 상세가 열림. 일일 할당량 안내가 보였고 측정 시도로 세지 않음.
- delete-05 뒤 장소가 남았는데 복원 버튼 위치를 누름. 해당 위치에 추가 버튼이 없었으며 추가되지 않음. 정정 기록을 request-times에 남김.
- delete-08 준비 중 복원 반영 전 좌표 입력으로 해수욕장 상세가 열려 일일 할당량 안내. 닫고 다시 준비했으며 동시 시도는 준비가 맞은 뒤 한 번만 수행.
- 순서 시험 뒤 A에서 화면을 나갔다 다시 들어가 메모 초안을 정리함. SSE 재연결 원인이 될 수 있으므로 서버 연결 기록과 대조 필요.
- 실제 버전·activity 값은 아직 미확인. UI에서 별도 조회 경로를 확인하지 못했고 운영 DB를 조회하지 않음.
